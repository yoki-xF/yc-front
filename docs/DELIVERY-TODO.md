# 易彩 H5 开发与验收清单

2026-11-11。P0 是首轮交付闭环，P1 紧随其后。条目打勾代表已开发、已部署至测试环境并按验收条件通过；仅写完代码时记录提交号，不打勾。既有分项证据见 FUNCTION-CHECKLIST.md。

| 负责人 | 模块 | 首批 | 复核 |
|---|---|---|---|
| Mac mini | 员工端、老板端 | E1，两店调拨与订票入库 | 本机验收与反馈；Mac mini 修复 |
| 本机 | 平台管理、直播 | P1，平台账号权限入口；L1，直播媒体契约 | Mac mini 独立复核；本机修复 |

## 员工端 · Mac mini

- [ ] **E1 · P0 订票与两店调拨**：订票确认入库；调入申请、调出确认或拒绝、取消及待处理历史。验证双方员工视图、来源库存不足、价格变化、旧版本、重复提交及库存守恒；仅接安全接口。
- [ ] **E2 · P0 完整营业日**：新店开店 → 早盘 → 营业数据 → 晚盘/资金 → 结店 → 日报；覆盖跨午夜仍归开店日、零库存、重复提交、未确认调拨阻止结店、并发版本冲突。对照已确认的资金账差公式与门店/个人统计口径。
- [ ] **E3 · P0 备付金与凭证**：两名员工看到同一门店共享流水，越店拒绝；原请求跨日查询、断网恢复；合成图片上传、预览、越权与大小限制；手机选图。
- [ ] **E4 · P1 促销与资料**：促销正常提交、旧版本冲突、断网原请求核对；个人资料与头像权限、操作指引、真机登录恢复及长日期查询。活动未知结果没有可靠核对路径前不允许盲重试。

## 老板端 · Mac mini

- [ ] **B1 · P0 初始化与账务更正**：合成新店首次初始化，重复与并发拦截；各类已结店更正须有原因、版本、审计，受影响库存、余额及日报一致重核。
- [ ] **B2 · P0 人员与权限**：组织内账号开通、停用、重置和角色/门店范围；停用保留历史关联；老板不得管理其他组织或授予超出自身范围的权限。
- [ ] **B3 · P1 经营配置与目录**：物料/成本新增、修改、软删除；门店、班次、促销、返佣、目标；校验有效期、历史引用、停用以及营业后的限制。
- [ ] **B4 · P1 排班与报表**：排班写入和冲突处理，返佣盘点新增及营业日归属；记录分页、长范围报表及授权导出，导出与页面汇总一致。

## 平台管理 · 本机

- [ ] **P1 · P0 平台入口与账号**：核对已有接口、权限和测试；平台菜单按权限出现；账号、角色、数据范围、重置、停用，核验员工/老板不可进入和越权请求被拒绝。
- [ ] **P2 · P0 组织管理**：租户、套餐、部门、岗位及配额；覆盖停用、过期、历史关联、组织间隔离及并发写入。
- [ ] **P3 · P1 平台配置**：菜单、字典、公告、站内通知；列表、详情、写入权限及回读，敏感字段脱敏。
- [ ] **P4 · P1 日志与导入导出**：登录/操作日志分页、范围与导出；导入逐行校验，错误可追踪，重复导入有明确处理。第三方支付、短信及外部邮件继续暂缓。

## 直播 · 本机

- [ ] **L1 · P0 媒体与鉴权契约**：固定官方 ARM64 容器摘要，隔离部署；发布/观看凭证绑定场次、路径、权限与有效期；验收错误路径、越权、过期和结束后的拒绝。已实测 macOS 原生 WHIP 推流和 RTSP 解码；Docker Hub 拉取超时，容器及 WHEP 尚未验证。
- [ ] **L2 · P0 H5 开播与播放**：摄像头麦克风预览、权限失败、静音、关闭设备；真实媒体状态驱动“直播中”；观看页播放/断流提示、结束直播、分享登录后回跳。
- [ ] **L3 · P0 测试环境双设备**：核验公网媒体路径；实际 iPhone/Android 或两台设备开播与观看、断线恢复、结束、重复开播、未授权观看。记录码率、CPU/内存及连接结果。带宽扩容另议，测试通过不代表容量承诺。
- [ ] **L4 · P1 房间运营**：编辑、停用、封面、配额和场次记录；关闭后分享链接有明确状态；公开分享另按授权规则设计。首版不做转码、录制或连麦。

## 合作与交付

- 每次只交付一个明确批次，Mac mini 从独立分支修改；不新增项目副本、不覆盖未提交文件。前后端共享入口、权限、迁移文件先列清楚再合并。
- 开发方提交代码、改动路径、迁移/配置、测试结果和剩余缺口；验收方基于准确提交和独立测试数据写明步骤、预期、实测、证据及复验结果。
- 发现问题：验收方给复现步骤 → 原开发方修复 → 验收方复验；业务账务核对数据、库存、日报及审计，不只看页面提示。
- 所有可交付批次经自动检查和 Mac mini 测试部署，再做接口、界面、真机和权限验证。浏览器受限的项目记待真机；未验收不打勾，不动生产。
