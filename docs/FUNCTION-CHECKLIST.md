## 平台管理

账号、角色、权限/数据范围、部门、岗位、租户、套餐、菜单、字典、公告、操作/登录日志、站内通知均尚缺对应 H5 完整管理页，后端已有接口需逐项核对。导入/导出需按各自权限实现；不能以一个泛化表单跳过版本及安全控制。

## 明确排除或暂缓

- 已废弃：代码生成器、网页生成/设计和旧微信运行能力。
- 暂缓：支付/退款/转账/钱包等实际支付服务、短信验证、外部邮件及社交平台集成。保持默认关闭，等待用户确认方案。
- 保留：促销、返佣、排班考勤；人工资金/移动支付账务记录不属于真实第三方支付调用。
- 旧 tests/ 暂留为规则核对依据，不能把未运行旧测试计入 H5 通过数。

## 推进顺序

1. 员工完整营业日：早盘→营业数据→晚盘/资金→结店→报表。
2. 订票、调拨、现金流水、活动与凭证。
3. 老板初始化、财务更正、目录及人员权限管理。
4. 平台管理和导入导出。
5. 全量角色回归、真实手机 UI、完整营业日验收。每批独立测试站验证，最后才讨论生产启用。
