# 易彩移动 H5

员工、老板和平台管理的统一移动 Web 前端。2026-11-06 用户确认废止微信小程序，现已移除微信页面、组件、启动配置和 wx 网络/存储/文件适配器。前端在本仓库重新开发，后端继续使用 [yc-backend](https://github.com/yoki-xF/yc-backend) Spring Boot 单体服务。

## 运行

需要 Node.js 22.12+。

```sh
npm ci
cp .env.example .env.local
npm run dev
```

访问 `http://127.0.0.1:5173/`。开发服务仅监听本机；手机访问、HTTPS及公网发布尚未配置。默认浏览器请求同源 `/admin-api`；开发时在 `.env.local` 填写 `YC_API_PROXY` 为可访问的后端地址，或由反向代理将 `/admin-api` 转发后端。不能把前端已启动等同于后端已联通。

```sh
npm run check
npm run build
npm run preview
```

`dist/` 为静态发布产物；hash 路由无需服务器 SPA rewrite。禁止将账号密码、token、数据库配置放入前端环境变量或构建产物。

## 本批实现与边界

- Vue 3 + TypeScript + Vite + Vant，蓝白配色，手机优先，兼顾桌面宽屏。
- 组织登录、当前标签页会话、退出登录、未登录路由保护；请求带租户和token，账号切换拒绝旧响应；过期GET共用刷新，写请求不自动重放。
- 按真实权限显示九类经营查询：即开盘点、资金盘点、营业、返佣、成本、票种、员工、角色、排班。支持筛选、分页及详情；前端显示权限不替代后端鉴权。
- 门店经营报表对接统一营业日接口，保留金额精度、结店完整性、待核对和长ID规则。
- 上述接口已按现有后端契约编写，**本批未做真实账号后端联调**。浏览器实际检查仅覆盖登录、空字段提示及390px/320px布局，不代表登录后页面已验收。
- 营业日开关店、盘点提交、采购调拨、财务更正、附件、CSV、账号管理操作及平台后台需继续重建；没有伪造可用按钮。支付、短信、外部邮件/社交仍暂缓。

新代码在 `src/`，新测试由 Vitest 执行。纯业务规则迁入 `src/domain/`，部分预留规则尚未挂接页面。`tests/` 为暂留的旧平台回归参考，依赖已移除的微信运行代码，**不在当前测试范围内且不能运行**；用户已确认暂留为需求核对依据，随 H5 开发逐项替换。历史 `docs/` 过程记录不作为 H5 完成证据，当前进度只看 [H5 重建清单](docs/H5-MIGRATION.md)。不另建或部署旧小程序项目。
