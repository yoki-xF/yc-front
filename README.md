# 易彩统一原生微信小程序

员工、老板和平台管理共用本项目，按账号角色及权限展示功能。使用微信开发者工具导入本目录；后端独立仓库为 [yc-backend](https://github.com/yoki-xF/yc-backend)，采用单模块Spring Boot单体服务。

员工、老板、平台业务统一在本项目。已按2026-11-05功能取舍移除代码生成、表单生成、GoView、积木设计器、动态数据源与WebSocket测试页面；开发运维入口不再放在业务小程序。促销、返佣、排班考勤、固定经营报表和个人销量均保留。支付、短信及外部邮件/社交等能力仍暂缓，不真实调用。

`utils/config.js` 默认连接本机 `http://127.0.0.1:48080/admin-api`；运行后端前按其新空库说明初始化独立数据库。真机需要独立HTTPS和微信合法域名；不得把localhost配置当作手机可访问地址，也不要将账号密码放入源码。

精简后65组Node测试文件通过，注册页面49个；检查不代替真实MySQL、完整营业日与真机验收。后端已在Mac mini独立Docker内网完成空库初始化、经营设置、双员工营业日及双店调拨核算联调；尚未公网部署或上传微信。Mac mini开发者工具登录已过期，需要重新登录后才能打开新项目。

运行页面测试：`for test in tests/*.test.js; do node "$test" || break; done`。本项目和后端是后续唯一开发源码，不再使用旧员工端、老板端或网页管理端项目目录。

隔离联调：`tools/live-acceptance.cjs` 使用原生请求/API模块，通过专用Docker后端验证10项真实交互。仅在测试环境显式设置私有 `YC_ACCEPTANCE_CREDENTIALS_FILE` 后运行；凭据与令牌不写入报告。该检查不替代完整营业日和真机操作。

经营设置在老板工作台及管理入口中按权限显示。仅允许首次资金库存初始化前设置，开始营业后锁定；修改保留原因和版本审计。个人销量仅电彩与竞彩，资金、库存和盈亏统一归门店。

运维接口与底层Redis、数据库、任务、通知、附件和认证服务按后端实际依赖保留。小程序不再提供任意OAuth客户端/令牌管理；内部登录与刷新退出仍正常使用。旧源码/功能可从Git历史追溯，不将开发工具重新作为业务功能迁回。
